# Viu-Shield-Thenhat
🛡️ ViU Shield

Advanced Android APK Protection & Anti-Tampering System

ViU Shield is an Android security project focused on APK integrity verification and anti-tampering protection.

🚀 Features

- APK Integrity Check – Verify APK files using SHA-256 hashes.
- Anti-Tampering – Detect unauthorized modifications.
- Digital Signature Verification – Verify the authenticity of protection data.
- Native Protection – Support for native C++ libraries (".so").
- Automated Build – Build Android APKs using GitHub Actions.
- Mobile-Friendly Development – Designed to support a development workflow without a PC.

🎯 Project Goals

The goal of ViU Shield is to develop a practical Android APK protection solution that makes unauthorized modifications easier to detect.

🛠️ Technologies

- Kotlin / Java
- C++
- Android SDK
- Android NDK
- Gradle
- GitHub Actions
